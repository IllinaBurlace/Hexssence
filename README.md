# Hexssence

[![powered by hexdoc](https://img.shields.io/endpoint?url=https://hexxy.media/api/v0/badge/hexdoc?label=1)](https://github.com/hexdoc-dev/hexdoc)

Resource generation addon for Hex Casting

## IMPORTANT:
This mod does NOT add any recipes on its own.  
The recipe format is shown in `common/src/main/resources/data/hexssence/recipes/spells/`  

Tags do not work in recipe definition.  
I cannot change that easily (though will accept PRs that do)

Extraction recipes ignore any inputs outside of the first one defined.  
I can change that if need be.
