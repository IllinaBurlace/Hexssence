      Essences

      Strange, some of these scrolls imply that basic items such as cobblestone are not discrete forms, but are instead amalgamations of even baser Essences.


      I wonder if I can exploit this...


      I've devised a way to store a large quantity of any one Essence.
      To store an Essence in a jar, I can simply interact while holding a matching essence.
      Interacting again within a short timeframe deposits every matching essence in my inventory.
      Punching the jar with an empty hand or essence extracts one of the contained essences into my hand, and crouching as I do so extracts a full stack.

                  Analysis

                  Essence Crafting seems to require a new iota form, called a Recipe iota.
                  The only way I've found to generate these iotas is Analysis, which I've detailed on the next page.


                  Analysis (entity → recipe)

                  • Renders
                    • Palettes
                      Your browser does not support visualizing patterns. Pattern code: aqqqqqwaeaeaeaeaea

                      Remove an item entity, then add an iota representing the combination recipe for that item to the stack.
                      Successful analyses tear the item apart.

                      Mishaps if target does not have a valid combination recipe.
                      Costs 5 Charged Amethyst.
