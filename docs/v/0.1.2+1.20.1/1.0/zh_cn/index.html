      我设计了大批量存储单种源质的方式。
      手持匹配源质时，与源质罐交互即可存入。
      在短时间内重复交互，会将所有匹配的源质返还至我的物品栏。
      空手或手持源质敲击源质罐，可从罐中取出一份源质；蹲下后重复此行为则能取出一整组。
